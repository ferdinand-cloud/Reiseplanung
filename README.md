# Reiseplanung

Reiseplan als Web-App (PWA) für iPhone: Karte, Wunschliste, Tagesplan, U-Bahn-Routen, Standort.

Installation: Seite in Safari öffnen › Teilen › „Zum Home-Bildschirm“.

Karte: OpenFreeMap (© OpenMapTiles, © OpenStreetMap-Mitwirkende) · Kartenbibliothek: MapLibre GL JS (BSD) · ÖPNV: MTA
